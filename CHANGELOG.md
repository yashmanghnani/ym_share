
## 1.0.0

* Upgraded the package and example app for Flutter 3.47.2 and Dart 3.13.
* Migrated Android builds to Gradle Kotlin DSL, AGP 9.1, Gradle 9.3.1, Java 17, and SDK 36.
* Migrated the example app to Flutter's modern Gradle plugin loader and removed Android V1 embedding code.
* Updated AndroidX dependencies and raised the Android minimum SDK to 24.
* Raised the iOS deployment target to iOS 15 and refreshed the podspec metadata.
* Replaced the deprecated `pedantic` setup with `flutter_lints` 6.
* Updated the example app for the current `image_picker` API and documented the release.
